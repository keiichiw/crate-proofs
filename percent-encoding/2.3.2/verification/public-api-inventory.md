# Public API inventory and feasible scope

This document defines the intended proof scope for the percent-encoding 2.3.2 fork and the claims each API model is meant to establish. It is a scope inventory, not a run-status report; use [results.md](results.md) for current audited status and evidence. Source-level contracts, isolated probes, and earlier byte-core runs are not substitutes for the current integrated audit. The historical 21-bundle result remains historical evidence.

The scope column distinguishes included behavioral claims from explicitly excluded claims. Current selected/open/excluded status and evidence belong in `results.md`. Native checks and differential comparisons are separate evidence from Creusot proofs. The proof-only gates do not remove runtime methods from ordinary builds.

| Public API or behavior | Ownership | Intended model / scope | Scope |
|---|---|---|---|
| `percent_encode_byte` | This crate | Exact unconditional three-byte uppercase `%HH` output, including `%20`, via the checked numeric helper and UTF-8 boundary. | Included in selected scope; status in `results.md` |
| `percent_encode`, `utf8_percent_encode` | This crate | Constructors preserve the exact remaining input bytes and configured four-word `AsciiSet` mask. | Included in selected scope; status in `results.md` |
| `PercentEncode::clone` | This crate | Clone preserves the current remaining byte suffix and configured mask. Cloning a partly consumed iterator clones that current state. | Included in selected scope; status in `results.md` |
| `PercentEncode::eq`, `Eq` | This crate | Equality means exact remaining raw input bytes and exact configured mask; it does not compare rendered or eventual output. Two clones may cease to compare equal after only one has been consumed. | Included in selected scope; status in `results.md` |
| `PercentEncode::next`, `IteratorSpec` | This crate | Each step emits one valid encoded chunk and relates the visited chunks plus new suffix to the encoded-chunk model. The completion/production relation and its checked laws are in scope. | Included in selected scope; status in `results.md` |
| `PercentEncode::size_hint` | This crate | Lower bound is zero for empty input and one otherwise; upper bound is the remaining byte length. This is a per-method contract, not a claim about every standard-library consumer of `Iterator`. | Included in selected scope; status in `results.md` |
| `Display for PercentEncode` | This crate | The model records requested chunk writes, their order, and returned success/failure status. On failure, later chunks are not requested. It does not model rendered output or effects inside the formatter's underlying writer. | Included in selected scope; status in `results.md` |
| `From<PercentEncode> for Cow<str>` (`alloc`) | This crate | Result UTF-8 bytes equal the flattened encoded chunk stream; the borrowed/owned branch is characterized by whether the stream has at most one or at least two chunks. | Included in selected scope; status in `results.md` |
| `percent_decode`, `percent_decode_str` | This crate | Constructors preserve the complete source bytes as remaining decoder state. | Included in selected scope; status in `results.md` |
| `PercentDecode::clone` | This crate | Clone preserves the current remaining iterator suffix, including a partly consumed iterator's state. | Included in selected scope; status in `results.md` |
| `PercentDecode::next_byte`, `Iterator::next`, `IteratorSpec` | This crate | The step decodes a valid `%HH` triplet and otherwise returns the first byte literally, with exact suffix consumption. Iterator production relates visited bytes and remaining suffix to `decoded_trace`; completion and checked production laws are in scope. | Included in selected scope; status in `results.md` |
| `PercentDecode::size_hint` | This crate | Lower bound is `ceil(remaining_bytes / 3)` and upper bound is the remaining byte length. The body contract is distinct from blanket claims about default `Iterator` methods. | Included in selected scope; status in `results.md` |
| `From<PercentDecode> for Cow<[u8]>` (`alloc`) | This crate | Decoded content is related to `decoded_trace`; unchanged input may be borrowed, while changed input is owned, with the specified length relation. Allocation details are not modeled. | Included in selected scope; status in `results.md` |
| `PercentDecode::decode_utf8` (`alloc`) | This crate | Strictly decodes the percent-decoded byte stream. Successful borrowed/owned content, validity, and the observed `Utf8Error::valid_up_to` / `error_len` values are related to the UTF-8 models. | Included in selected scope; status in `results.md` |
| `PercentDecode::decode_utf8_lossy` (`alloc`) | This crate | Output scalars follow the standard library's lossy UTF-8 model over decoded bytes; the valid/invalid borrowed-versus-owned behavior is stated in the contract. | Included in selected scope; status in `results.md` |
| `AsciiSet::EMPTY`, `CONTROLS`, `NON_ALPHANUMERIC` | This crate | Exact four-word masks. | Included in selected scope; status in `results.md` |
| `AsciiSet::contains`, `should_percent_encode` | This crate | Membership is specified for ASCII bytes; percent-encoding is true for non-ASCII bytes or members of the configured set. | Included in selected scope; status in `results.md` |
| `AsciiSet::add`, `remove` | This crate | Exact one-bit set/clear and preservation of other words, only under `byte < 128`. Out-of-domain indexing may panic and has no specified behavior. | Included in selected scope; status in `results.md` |
| `AsciiSet::union`, `complement`, `Add`, `Not` | This crate | Wordwise OR and bitwise complement. | Included in selected scope; status in `results.md` |
| `AsciiSet::eq`, `Eq` | This crate | Equality is exact equality of all four mask words. | Included in selected scope; status in `results.md` |
| `Debug for AsciiSet`, `PercentEncode`, `PercentDecode` | This crate | Checked request trace of struct name, ordered field names, typed field-value models, and `finish` status. It excludes rendered text and sink-side effects. | Included in selected scope; status in `results.md` |
| `AsciiSet::mask_words` | This crate | Opaque logical view of the exact four private mask words; native field visibility is unchanged. | Included in selected scope; status in `results.md` |
| `percent_hex_value`, `after_percent_sign`, `percent_encoded_bytes`, size-hint helpers, Cow/UTF-8/format trace helpers | Private to this crate | Checked helper contracts used to compose the public models above. They are not additional public APIs. | Supporting targets included; status in `results.md` |
| `static_assert` | This crate | Compile-time internal assertions are outside the runtime public-API model. | Excluded from behavioral claims |
| Other inherited/default trait methods (`Iterator`, `PartialEq::ne`, `Clone::clone_from`) | Rust standard library, composed with this crate's implementations | They are not individually specified or proven here. The crate-owned `next`, `size_hint`, `IteratorSpec` methods/laws, equality, and explicit clone contracts are tracked. | Excluded unless separately targeted |

The ASCII-set `add` and `remove` contracts intentionally cover only the index-safe domain `byte < 128`. For Debug, checked wrappers tie each actual `DebugStruct` call to a typed ghost event. This request trace establishes call structure and supplied values only; it makes no claim about final text, formatter history, or writer effects. Standard-library `DebugStruct` calls are modeled by signatures only.

The UTF-8 result models rely on the standard-library boundaries listed in [assumptions.md](assumptions.md). `Utf8Error` adequacy means that the two public observers used by the proof agree with the strict error model; it does not expose or prove the internal representation of `Utf8Error`. Likewise, the lossy model constrains returned scalar content and the stated Cow variant, not allocation strategy.
