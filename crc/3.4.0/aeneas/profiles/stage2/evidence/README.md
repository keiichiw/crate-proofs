# Archived evidence

`summary.json` describes the original recorded run, not a new verification.
`archive.json` identifies the complete original records, stored locally outside Git.
Their archive availability is **local-only**; no public download is currently provided.
`fixtures.json` is the explicit inventory of immutable inputs retained for compatibility checks.

Paths in the original records resolve inside the archive's `payload/` tree.
Follow the repository publication guide for integrity checking and safe restoration.
